# 飲みニケーションAIアプリ 🍻

AIと音声で会話しながら飲みニケーションができるWebアプリです。

## 機能

- 🎤 **音声入力による会話** - Web Speech APIを使用したリアルタイム音声認識
- 🔊 **音声出力による応答** - ブラウザの音声合成機能でAIが話します
- 👥 **複数の飲み相手キャラクター** - 4種類の異なる性格のAIキャラクターから選択
- 💭 **会話履歴の保存** - サーバーサイドのファイルシステムに会話を保存し、あなたの話を覚えています
- 🎨 **モダンなUI** - Tailwind CSSを使用した美しいデザイン

## 技術スタック

- **フロントエンド**: Next.js 14 (App Router), React, TypeScript
- **スタイリング**: Tailwind CSS
- **AI**: OpenAI GPT-4o-mini
- **音声**: Web Speech API (音声認識), Web Speech Synthesis API (音声合成)

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定

`.env.local`ファイルを作成し、以下を追加：

```
OPENAI_API_KEY=your_api_key_here
```

OpenAI APIキーは [https://platform.openai.com/api-keys](https://platform.openai.com/api-keys) から取得できます。

### 3. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## 使い方

1. **飲み相手を選択** - 4人のキャラクターから好きな人を選びます
   - タケシ: 陽気で話好きな先輩タイプ
   - ユキ: 落ち着いた雰囲気の聞き上手
   - ケンジ: テンション高めの盛り上げ役
   - サクラ: 優しく気遣いのできる後輩タイプ

2. **マイクボタンをクリック** - 青いマイクボタンを押して話しかけます

3. **会話を楽しむ** - AIがあなたの話を聞いて、自然に応答します

4. **会話履歴** - 過去の会話は自動的に保存され、次回同じキャラクターを選ぶと続きから会話できます

## 会話履歴の保存

会話履歴はサーバーサイドのファイルシステムに保存されます：
- 保存先: `data/conversations/` フォルダ
- ファイル形式: JSON（各キャラクターごとに `{characterId}.json` として保存）
- 自動作成: 初回保存時にフォルダが自動作成されます

## 注意事項

- 音声認識機能はChrome、Edge、Safariなどのモダンブラウザで動作します
- マイクの使用許可が必要です
- OpenAI APIキーが必要です（有料）
- 会話履歴は `data/conversations/` フォルダに保存されます（このフォルダは `.gitignore` に含まれています）
